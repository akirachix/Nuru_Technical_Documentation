## Core Principles

**Design Principles**

eLoop minimizes operational friction by coupling automated edge metrics directly with an instant **Digital Showroom** network.



### Guiding Principles

#### 1. Local-First Processing
We completely eliminate cloud server strain and internet dependencies by executing neural calculations directly at the conveyor belt.

```text
[Raspberry Pi 5 Camera] ──(Raw Image)──> [Raspberry Pi 5 + YOLOv8] ──(Light Metadata)──> [Cloud Server]
```

#### 2. High-Density Traceability
Every incoming raw material batch is continuously monitored, automatically scored, and tracked across a strict state machine.

```text
[Material Intake] ──> [AI Recognition] ──> [Composition Lookup] ──> [Dynamic Value Tier] ──> [Marketplace Listing]
```

#### 3. Two-Tenant Architecture
Data is structurally separated at the API layer to provide isolated dashboard interfaces tailored to distinct user roles.

```text
                           ┌──> [Recycler PWA] ────> (Intake / Sorting / Inventory Management)
[Unified FastAPI Backend] ─┤
                           └──> [Refinery Mobile] ──> (B2B Showroom Catalog / Batch Booking)
```
