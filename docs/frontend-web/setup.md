## Setup and Installation

The steps guided us to install Node.js and set up the frontend project on our local machines:

### 1. Downloaded Node.js
* Opened the web browser and navigated to the official download page: [Node.js Downloads](https://nodejs.org).
* Selected the **LTS (Long Term Support)** installer recommended for Linux operating system.

### 2. Run the Node.js Installer
* Opened the downloaded installer file on our systems to launch the setup wizard.
* Clicked through the prompts, accepting the licensing agreement, and keeping the default installation settings.
* Completed the wizard to finish installing Node.js and the Node Package Manager (NPM).

### 3. Verified the Installation
* Opened the Linux terminal.
* Verified Node.js is installed correctly by running: `node -v`
* Verified NPM is installed correctly by running: `npm -v`

### 4. Installed Project Dependencies
* Opened the terminal, changed directories into our project's root folder, and installed the required project packages.
* Run the installation command: `npm install`

### 5. Started the Project
* Launched the Next.js local development server to run the application code locally.
* Run the development command: `npm run dev`

### 6. Opened the Application
* Launched our web browser when the compiler finished loading the local codebase.
* Navigated directly to the local server address: `http://localhost:3000`
