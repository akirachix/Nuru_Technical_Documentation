# Frontend Web Overview

### Overview
The frontend web serves both **recycling centers** and **refineries**. It is engineered as a Progressive Web Application (PWA) that is intentionally built so it can be used by operators wearing gloves at the sorting line.

### Who the Frontend Serves Exactly

#### 1. Recycling Centers
* **Who they are:** On-site warehouse workers and local facility operators.
* **How they use it:** They use the PWA directly at the physical sorting line, even while wearing gloves, to register incoming devices, interact with live visual scanning feeds, and manage localized inventory batches.

#### 2. Refineries
* **Who they are:** Industrial extraction facilities and refinery buyers.
* **How they use it:** They access the Digital Showroom to browse, filter, and view verified e-waste batch metrics in real time to coordinate downstream procurement.
