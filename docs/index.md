## Technical Overview

The eLoop Platform is engineered to bridge the transparency gap between e-waste recovery centers and industrial metallurgy processing refineries. By digitizing raw physical waste streams into structured, predictable data batches, Nuru transforms environmental overhead into scalable supply chain solutions.

### Core Ecosystem Components

* **Unified Backend API Engine:** High-performance REST and stateful WebSocket routers built with **FastAPI** and **PostgreSQL**.
* **Operator Interface (PWA):** A highly responsive **Next.js** application designed for fast on-site e-waste lot ingestion and processing.
* **Refinery Portal (Mobile):** A cross-platform **Flutter** native app delivering transaction concurrency and atomic booking flows for buyers.
* **Computer Vision Module:** An edge-hardware framework running custom **YOLOv8s** weights over active conveyor belt setups.
